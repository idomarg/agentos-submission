# AgentOS — Workflow Overlay for AI Coding Agents

> שכבת עבודה (Overlay) קבועה שמונעת מסוכן פיתוח כמו Claude Code לשכוח הקשר בין סשנים — באמצעות קבצי פרויקט קבועים, פקודות, Hooks, חיבור ל-Linear ותיעוד החלטות ולמידות.

---

## הבעיה

סוכני קוד מבוססי AI (Claude Code ודומיו) **מאבדים הקשר בכל סשן חדש**. כל פתיחת חלון מתחילה מאפס:

- הסוכן לא זוכר אילו החלטות ארכיטקטוניות כבר התקבלו.
- הוא חוזר על טעויות שכבר תוקנו בעבר.
- הוא לא יודע מה הסטטוס הנוכחי, על איזה branch עובדים, ומה המשימה הפעילה.
- אין מקור אמת אחד למה "נעשה", מה "בעבודה" ומה "הבא בתור".

התוצאה: בזבוז זמן על הסבר חוזר של הקשר, החלטות שנשכחות, ועבודה כפולה — במיוחד כשעובדים על פני כמה ימים, כמה סשנים, או כמה סוכנים במקביל.

---

## הפתרון

**AgentOS** הוא Overlay — שכבה דקה של קבצים וקונבנציות שמתלבשת על **כל** repo, בלי לשנות את הקוד עצמו. הוא נותן לסוכן זיכרון מתמשך דרך קבצים שהוא קורא בתחילת כל סשן וכותב אליהם בסופו.

הרעיון המרכזי: **הזיכרון של הסוכן הוא קבצים ב-repo, לא state פנימי.** מה שכתוב בקובץ — נשמר. מה שלא — נשכח.

---

## מה ה-Overlay כולל

| רכיב | תפקיד |
|---|---|
| **Project Memory Files** | קבצי markdown קבועים: `CLAUDE.md`, `AGENTS.md`, `STANDUP.md`, `DECISIONS.md`, `LEARNINGS.md`, `CHANGELOG.md`. |
| **Commands** | Slash commands שמגדירים זרימות חוזרות: `/prime`, `/start-issue`, `/review-pr`, `/wrap-up`. |
| **Hooks** | סקריפטים שרצים אוטומטית בתחילת/סוף סשן ומזריקים או שומרים הקשר. |
| **Linear Integration** | Linear כמקור האמת לכל משימה — issue אחד למשימה, סטטוס, branch, וקבלה (acceptance criteria). |
| **Docs / Memory Layer** | שכבת תיעוד ארוכת־טווח: החלטות, למידות, ארכיטקטורה. |

---

## איך זה עובד

מחזור חיים של סשן עבודה אחד:

```
/prime         → הסוכן קורא CLAUDE.md + STANDUP.md + DECISIONS.md, מבין איפה עצרנו
/start-issue   → תופס משימה מ-Linear, פותח branch, מגדיר Acceptance Criteria
[work loop]    → מבצע את העבודה מול ה-criteria
/review-pr     → בודק את ה-PR מול ההחלטות והסטנדרטים
/wrap-up       → מעדכן STANDUP / CHANGELOG / DECISIONS / LEARNINGS לסשן הבא
```

הכלל הברזל: **כל סשן מתחיל בקריאה (`/prime`) ומסתיים בכתיבה (`/wrap-up`).** כך הסוכן הבא — בין אם זה אתה מחר, או סוכן אחר במקביל — ממשיך מאיפה שעצרת.

---

## דוגמת שימוש עם Linear

Linear הוא מקור האמת. במקום שהסוכן "ימציא" מה לעשות:

1. כל משימה משמעותית = issue ב-Linear עם Acceptance Criteria.
2. `/start-issue` תופס את ה-issue הבא שאפשר לתבוע, נועל אותו (assignee + status + branch), ופותח branch בשם שתואם ל-Linear.
3. הסוכן עובד **רק** מול ה-criteria של אותו issue.
4. בסיום — PR, מיזוג, ועדכון ה-issue בתגובה בעברית פשוטה.

זה מונע שני סוכנים מלעבוד על אותה משימה, ושומר תיעוד מסודר של מה נעשה ולמה.

---

## דוגמת שימוש עם קבצי פרויקט

גם בלי Linear, ה-Overlay עובד דרך הקבצים:

- **`STANDUP.md`** — "איפה אנחנו עכשיו": סטטוס, משימה פעילה, branch, צעדים הבאים, חסמים.
- **`DECISIONS.md`** — החלטות נעולות. הסוכן לא חוזר לדון בהן.
- **`LEARNINGS.md`** — לקחים שחוזרים על עצמם (gotchas, דברים שנשברו).
- **`CHANGELOG.md`** — לוג שינויים לפי issue ו-branch.

בתחילת כל סשן הסוכן קורא את הראשונים; בסוף — מעדכן את כולם דרך "שער ניתוב" (ראה [AGENTOS.md](AGENTOS.md)).

## מה נחשב MVP (מה עובד עכשיו)

- ✅ **Project Memory Files** — תבניות מלאות ומוכחות בפרויקטים אמיתיים.
- ✅ **Commands** — מתועדים כ-slash commands ל-Claude Code.
- ✅ **Linear workflow** — קונבנציה מלאה לניהול issues, branches ומיזוג.
- ✅ **שני case studies אמיתיים** — OurMoney ו-Nap Inventory (ראה [`examples/`](examples/)).

## מה עדיין planned / future

- ⏳ **Installer אוטומטי** — פקודה אחת שמתקינה את ה-Overlay ב-repo חדש (כרגע: העתקה ידנית של templates).
- ⏳ **Hooks אמיתיים** — הדוגמאות ב-[`hooks/`](hooks/) ממחישות את הרעיון; אינטגרציה מלאה לסביבה היא צעד הבא.
- ⏳ **אינטגרציית Linear API עמוקה** — סנכרון דו־כיווני אוטומטי בין הקבצים ל-Linear.

> 🟡 **שקיפות:** AgentOS הוא כיום **אוסף תבניות + קונבנציות שמוכחות בשימוש אמיתי**, לא מוצר מותקן בלחיצה. החלקים שעובדים בפועל מסומנים MVP; השאר מסומן Future.

## למה זה רלוונטי לבעלי עסקים / builders / AI consultants

- **בעלי עסקים** — מקבלים תהליך פיתוח AI שלא "מאבד את החוט" באמצע, עם תיעוד החלטות שאפשר לחזור אליו.
- **Builders / Vibe coders** — מפסיקים להסביר את אותו הקשר בכל פעם מחדש; הסוכן ממשיך מאיפה שעצרת.
- **AI consultants** — מקבלים מסגרת חוזרת ומדידה לעבודה מול לקוחות, עם case studies להציג.
