# /wrap-up — סיכום סשן ועדכון קבצי memory

> Slash command של AgentOS. הצעד האחרון בכל סשן. הלב של "כתיבה בסוף".
> מיקום מותקן: `.claude/commands/wrap-up.md`

## מטרה

לסגור את הסשן במצב שממנו אפשר להמשיך — כך שהזיכרון לא ילך לאיבוד.

## שער הניתוב בארבע שאלות

נשאל **בכל** סוף סשן, גם כשהתשובה "לא":

1. **התקבלה החלטה ארכיטקטונית/מוצרית חדשה?** → עדכן `DECISIONS.md`.
2. **יש לקח חוזר / gotcha שכדאי לזכור?** → עדכן `LEARNINGS.md`.
3. **הייתה התקדמות רגילה?** → עדכן `CHANGELOG.md`.
4. **מה המצב הבא?** → כתוב מחדש את `STANDUP.md`.

> שתי השאלות הראשונות **מותנות** — אל תכתוב החלטה/לקח סתם כדי למלא. אבל **שאל** אותן בכל פעם.

## מה הפקודה עושה

1. מריצה את שער הניתוב ומעדכנת את הקבצים הרלוונטיים בלבד.
2. כותבת מחדש את `STANDUP.md` — סטטוס, משימה פעילה, branch, סטטוס סנכרון, צעדים הבאים, חסמים.
3. מעדכנת את ה-issue ב-Linear בתגובה קצרה **בעברית פשוטה** — מה נעשה.

## כללים

- **אל תעדכן `DECISIONS.md`** אלא אם התקבלה החלטה אמיתית.
- **אל תהפוך את `CLAUDE.md` ליומן סשנים** — הוא נשאר יציב.
- `STANDUP.md` הוא מצב נוכחי בלבד — ההיסטוריה הולכת ל-`CHANGELOG.md`.

## מתי משתמשים

בסוף יחידת עבודה משמעותית (issue/feature/נקודת עצירה הגיונית) — לא בכל סגירת חלון.
