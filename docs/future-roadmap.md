# Future Roadmap — AgentOS

מה הייתי ממשיך לבנות. מדורג לפי ערך מול מאמץ. הכל כאן **Future** — לא ממומש ב-MVP.

---

## אופק קרוב

### 1. Installer אוטומטי
פקודה אחת (`npx agentos init` או slash command) שמתקינה את ה-Overlay ב-repo חדש: מעתיקה templates, מזריקה סקשנים ל-`CLAUDE.md`, ומחברת commands. מחליפה את ההעתקה הידנית שב-`QUICKSTART.md`.

**ערך**: מוריד את חסם הכניסה מ-15 דקות לדקה. **מאמץ**: בינוני.

### 2. Hooks מחוברים
חיבור `session-start` ו-`stop` ל-Claude Code hooks האמיתיים — כך ש"קרא בהתחלה / כתוב בסוף" קורה אוטומטית, בלי להסתמך על האדם שיריץ `/prime` ו-`/wrap-up`.

**ערך**: הופך משמעת לאוטומציה. **מאמץ**: בינוני.

---

## אופק בינוני

### 3. אינטגרציית Linear API דו־כיוונית
סנכרון אוטומטי: סטטוס issue ב-Linear מתעדכן מ-`STANDUP.md` ולהיפך; `/start-issue` ו-`/wrap-up` קוראים/כותבים ל-Linear ישירות דרך ה-API.

**ערך**: מקור אמת אחד באמת, בלי עדכון כפול. **מאמץ**: בינוני-גבוה.

### 4. גילוי החלטות אוטומטי
זיהוי בזמן סשן שהתקבלה החלטה ארכיטקטונית, והצעה אוטומטית להוסיף אותה ל-`DECISIONS.md` — כדי שהחלטות לא יישכחו גם כששוכחים `/wrap-up`.

**ערך**: פחות החלטות אבודות. **מאמץ**: גבוה (דורש שיפוט).

---

## אופק רחוק

### 5. Vault זיכרון על־פרויקטלי
שכבת זיכרון שחוצה פרויקטים — לקחים והעדפות שנלמדו בפרויקט אחד זמינים בכולם (למשל דרך Obsidian או store מרכזי).

**ערך**: הסוכן "מתבגר" על פני פרויקטים. **מאמץ**: גבוה.

### 6. דשבורד מצב
תצוגה אחת (Telegram/web) של כל הפרויקטים תחת AgentOS: מה פעיל, מי תפס מה, מה חסום.

**ערך**: שליטה רב־פרויקטלית. **מאמץ**: גבוה.

---

## מה **לא** ב-roadmap (מכוון)

- **LLM בתוך ה-overlay** — AgentOS הוא תהליך וקבצים, לא מודל. הוא נשאר agnostic לסוכן.
- **נעילה לספק יחיד** — לא נקשור אותו ל-Claude Code בלבד; הקבצים צריכים לעבוד עם כל סוכן.
