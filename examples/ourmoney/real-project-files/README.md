# Real project memory files — OurMoney

הקבצים בתיקייה הזו **מבוססים על קבצי ה-memory האמיתיים** מהפרויקט החי OurMoney. המבנה, סוגי ההחלטות וזרימת העבודה נשמרו במלואם; פרטים מזהים/רגישים (כתובות workspace חיות, קטגוריות פיננסיות אישיות, שמות בתי עסק, וספירות מדויקות) **הוסרו או הוכללו** לצורך פרסום ציבורי. הם מצורפים כהוכחת שימוש אותנטית ב-AgentOS (במקום צילום מסך).

| קובץ | מה זה מדגים |
|---|---|
| [`STANDUP.md`](STANDUP.md) | מצב נוכחי חי — משימה פעילה, branch, צעדים הבאים, חסמים. |
| [`DECISIONS.md`](DECISIONS.md) | החלטות ארכיטקטוניות/מוצריות נעולות שנצברו לאורך הפרויקט. |
| [`LEARNINGS.md`](LEARNINGS.md) | לקחים אמיתיים מהשטח (gotchas של Supabase/Next.js/Vercel/worktree). |
| [`CHANGELOG.md`](CHANGELOG.md) | לוג שינויים מלא לפי issue ו-branch. |

> אלה הקבצים שמהם הסוכן קורא ב-`/prime` וכותב אליהם ב-`/wrap-up`. ה-`README` ושאר קבצי ה-`examples/ourmoney/` הם גרסה נרטיבית מקוצרת; **כאן** נמצאת זרימת העבודה האמיתית.

> 🔒 **הערת פרטיות:** הקבצים שומרים על מבנה זרימת העבודה האמיתית של AgentOS ועל הקשר תפעולי מייצג, אך מזהים ציבוריים, כתובות workspace חיות, ופרטים פיננסיים רגישים — הוסרו או הוכללו. ספירות מדויקות הוחלפו בערכים מקורבים בסוגריים (למשל `[~1.2k]`), וגיבובי commit פנימיים בתוך טקסט רץ סומנו `[commit]`.
